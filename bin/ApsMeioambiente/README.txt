Projeto: EcoMetrópole

Como executar:
1. Abra o projeto em uma IDE Java, como IntelliJ, Eclipse ou NetBeans.
2. Compile todos os arquivos da pasta src.
3. Execute a classe Main.java.

Funcionalidades:
- Home com botões para Jogo, Quiz e Sobre.
- Jogo de separação do lixo reciclável.
- Quiz ambiental com pontuação.
- Tela explicativa sobre meio ambiente nas grandes metrópoles.

Cores das lixeiras:
- Azul: papel
- Vermelho: plástico
- Verde: vidro
- Amarelo: metal
